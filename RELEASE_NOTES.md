# Release notes

## PWA v1.3.0

This is an architecture-hardening release based on the last proven working build. It keeps
user-visible behaviour and data compatibility while reducing duplicated live work, removing
deprecated directional icons on Android, documenting the cross-platform behaviour contract,
and adding executable source validation.

Full device/browser validation remains required for lifecycle, notifications, long active
sessions, database upgrade paths and installed-PWA service-worker replacement.
