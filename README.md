# Gym Progress PWA v1.5.1

Major exercise-identity and workout-usability release. Exercise names are presentation only; persistent user/programme exercise UUIDs now drive Progress and social comparison. A 191-exercise canonical catalogue is bundled for offline use, with cloud catalogue SQL included.

Highlights: canonical/local exercise linking, language-stable personal exercise names, programme-occurrence Progress, comparison-grade Estimated 1-rep max (e1RM), user-selected friend comparison, timed/mat exercises, compact supersets, max/plate-friendly ramp-up, Next information during ramp/rest, louder countdown cues, Tracker card, and simplified Advanced sections.

Before applying the Supabase catalogue SQL, read `supabase/SUPABASE_BACKUP_BEFORE_EXERCISE_MIGRATION.md`.
